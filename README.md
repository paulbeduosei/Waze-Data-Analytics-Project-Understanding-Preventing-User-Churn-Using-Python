# Waze-Data-Analytics-Project-Understanding-Preventing-User-Churn-Using-Python
# THIS PROJECT IS STILL IN PROGRESS

In this project, I stepped into the role of a data analyst at Waze, supporting a company-wide effort to reduce monthly user churn and improve long-term user retention.

Waze’s navigation app relies on engaged users to deliver real-time traffic insights. When users uninstall the app or stop using it, that value is lost. 

The goal of this project is to support the development of a churn prediction model that helps Waze identify who is likely to churn, why they churn, and when churn happens.
